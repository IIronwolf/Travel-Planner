# ✈️ Offline Indian Travel AI Agent

An intelligent, fully offline travel concierge designed to parse natural language queries, execute hybrid search (categorical SQL filtering + semantic vector matching), and generate structured day-by-day travel itineraries across India.

Powered by **Google ADK**, **Ollama (Llama 2 & nomic-embed-text)**, **SQLite** and **ChromaDB**, with a **Streamlit** web interface and a terminal CLI.

---

## ✨ Features

* **Natural language input**: describe your trip in plain English, e.g. *"5 day budget trip to Goa with friends, beaches and seafood"*.
* **Hybrid retrieval**: hard SQL filters (budget, duration, region, season, traveler type) combined with semantic vector search for vibe and preferences.
* **Day-by-day itineraries**: personalized markdown output generated by the Presenter Agent.
* **Two interfaces**:
  * **Streamlit web app** (`app.py`) with live pipeline progress, extracted constraints, itinerary view, itinerary download, query history, and retrieved-record inspection.
  * **Terminal CLI** (`main.py`).
* **100% offline**: runs locally with no external cloud API dependencies.

## 🏛️ Architecture & System Flow

```
+------------------+      +---------------------+      +---------------------+
| User Query (Text)| ---> | Orchestrator Agent  | ---> | TravelQuerySchema   |
+------------------+      | (Google ADK / Llama2)|     | (Pydantic JSON)     |
                          +---------------------+      +----------+----------+
                                                                  |
                                                                  v
+------------------+      +---------------------+      +----------+----------+
|  Presenter Agent | <--- |   Hybrid Retrieval  | <--- | SQL & Vector Search |
| (Markdown Output)|      | (Merges Constraints)|      | (SQLite + ChromaDB) |
+--------+---------+      +---------------------+      +---------------------+
         |
         v
+------------------+
|  CLI / Streamlit |
+------------------+
```

* **Orchestrator Agent**: Powered by Google ADK (`google-adk`) and local `llama2` via LiteLLM. Extracts structured travel parameters (destination, region, trip duration, budget tier, maximum daily budget, season, group archetype, and vibe keywords) into a validated `TravelQuerySchema`.
* **Hybrid Retrieval Engine**:
  * **SQLite (`tourism.db`)**: Performs hard filtering on numeric ranges (daily budget min/max, duration limits) and exact categorical tags (region, traveler archetype, seasons).
  * **ChromaDB (`chroma_db`)**: Runs dense vector similarity search using `nomic-embed-text` embeddings for subjective preferences (e.g., quiet beaches, Portuguese architecture, local seafood, hidden gems).
  * **Hybrid Ranker**: Merges exact SQL constraints with semantic similarity scores to return top destination matches.
* **Presenter Agent**: Formats dataset records into a personalized, daily travel itinerary.
* **Frontends**: `main.py` (terminal) and `app.py` (Streamlit) both call the same three-step pipeline: `parse_user_query` → `hybrid_search` → `format_itinerary`.

## 🚀 Quickstart Guide

### 1. Prerequisites

* Python 3.10+ installed.
* Ollama installed and running locally (`http://localhost:11434`).

### 2. Pull Required Models in Ollama

```bash
ollama pull llama2
ollama pull nomic-embed-text
```

### 3. Virtual Environment & Dependency Installation

Clone the repository, create a virtual environment, and install dependencies:

```bash
# Create virtual environment
python -m venv venv

# Activate environment (Windows)
venv\Scripts\activate

# Activate environment (macOS/Linux)
source venv/bin/activate

# Install required packages
pip install -r requirements.txt
```

> Make sure `streamlit` is listed in `requirements.txt` (add it, or run `pip install streamlit`).

### 4. Build the databases (first run only)

If `data/processed/` does not already contain `tourism.db` and `chroma_db/`, generate them:

```bash
python data/scripts/ingest_data.py
```

### 5. Run the app

**Option A: Streamlit web interface (recommended)**

```bash
streamlit run app.py
```

Then open the URL shown in your terminal (usually `http://localhost:8501`).

**Option B: Terminal CLI**

```bash
python main.py
```

## 🖥️ Using the Streamlit App

1. Type your travel request in the text box, or click one of the example prompts in the sidebar.
2. Press **Plan my trip ✈️**. A progress panel shows the three pipeline stages:
   1. Parsing the query with the Orchestrator Agent
   2. Querying SQLite and ChromaDB
   3. Formulating the itinerary with the Presenter Agent
3. Review the results:
   * **Understood constraints**: destination, duration, budget tier, plus all extracted parameters.
   * **Your itinerary**: the day-by-day plan, with a **Download itinerary (.md)** button.
   * **Retrieved destination records**: the raw matches from hybrid search, with per-stage timings (toggle in the sidebar).
4. Use the sidebar **top_k** slider to change how many destination records are retrieved (default: 2), and **Clear history** to reset past queries.
